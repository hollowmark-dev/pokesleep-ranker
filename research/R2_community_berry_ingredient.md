## 0. 結論（先に3行）

- **きのみタイプ**は「きのみの数S」が単独で頭ひとつ抜けている。異論はほぼ無い。次点の
  **おてつだいボーナス と おてつだいスピードM はソースによって順位が入れ替わる**（団体戦で見るか単体で見るか）。
- **食材タイプ**は「食材確率アップM」が必須級。ただし**きのみの数S は食材タイプでは減点**という
  はっきりした評価があり、ここが2タイプでいちばん差の出る項目。
- **せいかくは「▲で何が上がるか」より「▼で何が下がるか」で決まる**というのが共通認識。
  きのみでは 食材おてつだい確率▼ が**むしろ加点**になるのが特徴（いじっぱりが最適解とされる理由）。

**エナジー換算の目安**（重み決定でこれを基準にした）

- おてつだいスピードM（−14%）→ おてつだい回数 **+16.28%**
- おてつだいボーナス（−5%）→ 1体あたり +5.26%。**5体分を1体の手柄として集計すると +26.32%** (S13)
- きのみの数S（きのみとくい）→ 検証Wiki「厳選」は **「獲得エナジーが40%以上増える」** と明記 (S10)

> **2025–2026で効いている変化**
> 1. **サブスキル枠の開放Lv短縮（2026年6月）**。Lv70枠が現実的な射程に入り、
>    「Lv50までに何が揃うか」だけでなく **Lv70/80に何が来るか**も厳選対象になった (S26)。
>    雑談板でも 2026-09-11 時点で「80きのみS、80おてボ両方育ててます」といった書き込みが並ぶ (S41)。
> 2. **フレンドメダルの金確定枠ON/OFF**。金確定は**オフにできる**ようになり、
>    「食材とくいは金より青（食材確率アップM）が欲しい」という要求が実現可能になった (S5, S2)。
> 3. **げんき回復量▼の緩和（0.8→0.88）**。「げんき回復ボーナス1つあれば概ねカバーできる」ようになり、
>    げんき▼せいかくの忌避は当初よりやや和らいだ。ただし「常駐させるなら今も避ける」が主流 (S16, S29, S34)。
> 4. **EXモード（2025年夏〜）**でおてつだい時間が15%延びるため、
>    溢れにくくなり最大所持数アップの相対価値は下がり、速度系の価値は上がる方向 (S43の文脈)。

### 2-3. きのみタイプの意見対立

1. **おてつだいボーナス vs おてつだいスピードM**。
   - おてボ上位派: Game8 (S1・同格S)、検証Wiki厳選 (S10)、おがのブログ (S20: A vs B)、kengomon (S37)。根拠は**チーム全体効果の合算**。
   - スピードM上位派: ls_katoo (S30)、teke teke (S28、同列扱い)。根拠は**その個体単体の出力**。
   - **アプリでの解釈**: 個体評価アプリは「その個体を採用したときのチーム貢献」を測るのが自然なので、
     おてボをわずかに上に置くのが妥当。ただし差は小さくすべき。
2. **緩和論の存在**。S38（2026年）は「きのみS＋おてスピ▼でない」だけで十分と主張。
   きのみ得意は活躍フィールドが限られるので基準を甘くしてよい、という立場。
3. **妥協ライン**。S25 は「おてつだいスピードDOWNのせいかくではあるものの**きのみの数SとおてスピS/Mを持っていれば妥協する**」。
   S10（Wiki）は「きのみSがない個体で妥協する場合、おてボ以外ではおてつだいスピード上昇が一つの目安」。

### 3-3. 食材タイプの意見対立

1. **きのみの数S の扱い**が最大の対立点。
   - 減点派（多数）: Wiki「**性質と噛み合わず、あまり相性はよくない。所持数上限に達しやすくなり、食材収集が阻害される**」(S12)、
     ls_katoo「最大所持数アップが無い場合は、むしろ無い方が良い」(S30)、課金中毒者 ×評価 (S23)。
   - 加点派（少数・古い）: teke teke (S28, 2024) は食材タイプでも①に置く。
   - **結論**: 減点派が新しく数も多い。低い重みにし、**最大所持数アップとの併存で緩和**という条件を注記する。
2. **最大所持数アップの重要度**が「必須」〜「正直弱い」まで振れる。
   - 高評価: ぽいずみ（当たり枠）、Game8（A）、課金中毒者（無進化食材で3〜4時間差）。
   - 低評価: teke teke「極めて地味」(S27)、はりゅう「深く考えなくてよい」(S33)。
   - **分かれる理由は運用差**。こまめに回収する人は不要、朝まで放置する人は必須。
     個体評価アプリでは「中の上」に置き、注記で条件を示すのが無難。
3. **緩和論**（S33, S38）は「食材Mは青枠で出にくいのに必須扱いすると永久に終わらない」という
   厳選疲れへの反論として存在する。重み自体は変えず、合格ラインの話として扱うべき。

## 4. 論点別の深掘り

### 4-1. おてつだいボーナス（2025–2026の評価）

- **仕様**: チーム全員 −5%、**おてボ同士は最大−25%まで重複**、おてスピS/Mとも合算して**1匹上限−35%** (S6, S7)。
- **団体戦効果の換算**: 検証Wikiは
  「おてつだいスピードMは16.28%のエナジー増加率に対し、おてつだいボーナスは各ポケモン5.26%。
  **1体に集約すると26.32%相当となり、おてつだいスピードMを上回る**」(S13)。
  実測系では note まるげりーた (S42, 2024-05) が Lv60で1体825→1555エナジー/日、4体分6220エナジー/日と算出し、
  「**きのみ得意フィールドなら約1.6～1.8倍の効果**」と付記している。
- **おてスピMより上か**: **上に置くのが主流だが全会一致ではない**。
  Game8 はきのみ・食材とも同じS帯に並べ、おがのブログは食材でA（おてスピMはB）、
  ls_katoo は単体視点でおてスピMを上に置く。差は「±10点程度」の認識が実態に近い。
- **注意点（アプリ実装に効く）**: −35%上限がある。おてボ5体編成（−25%）＋おてスピM（−14%）は
  合計−39%で上限に当たり、**Mの一部が無駄になる**。個体単体スコアでは無視してよいが、
  UIに注記する価値はある。
- **とくい別の差**: 検証Wiki のおてボ項には**とくい別の価値差の記述は無い**（S13）。
  つまり「きのみでも食材でも同じくらい強い汎用枠」というのがコミュニティの扱い。
  ただし食材タイプでは §4-5 の金枠ジレンマがあるため、実運用上は一段落ちる。

### 4-2. きのみの数S：きのみタイプ vs 食材タイプ

| | きのみとくい | 食材とくい |
|---|---|---|
| 倍率 | きのみエナジー **1.5倍**（2個→3個） | きのみエナジー 2倍（1個→2個）だが**きのみは主収入ではない** |
| Wikiの評価 (S12) | 「自身の性質と合致し、**極めて相性がよい。採用基準のひとつとされることも多い**」 | 「**性質と噛み合わず、あまり相性はよくない。所持数上限に達しやすくなり、食材収集が阻害される**」 |
| 総合エナジー | **+40%以上** (S10) | 微増〜マイナス |
| 実務上の結論 | **最優先。無ければ妥協個体にすらしない**(S30) | **最大所持数アップが無いならむしろ無い方が良い**(S30) |

「2倍」という数字だけ見ると食材タイプでも強そうに見えるが、**所持枠の食い合い**が本質。
所持上限に達したポケモンは食材を拾わなくなりきのみだけを拾い続けるので、
きのみの数Sは「食材を集める時間を短くする」方向に働く。ここを取り違えると重み付けが壊れる。

### 4-3. 食材確率アップM（食材タイプ）

- +36%を**食材おてつだい確率に乗算**。Wikiは「元々の確率が高いほど食材おてつだいの頻度は大きく上がる」(S14) と
  書いており、**食材とくい（元の確率が高い）ほど恩恵が大きい**乗算スキル。だから食材タイプで必須級になる。
- 検証Wiki厳選は「**食材確率の方がおてつだいスピードよりも倍率が高く、前者を優先**」(S10) と明言。
  1.36倍（食材M）> 1.163倍（おてスピM）という単純比較が根拠。
- ただし**青枠**なので金確定枠が増えると出なくなる。Game8 厳選ページはこれを
  「食材得意やスキル得意では**青スキルのほうが優先度の高い**」ため
  「猶予とも言えるフレンドレベルに注意が必要」(S2) と警告している。

### 4-4. 最大所持数アップ：効くのはどんなとき

明確に条件付き。以下がすべて重なるほど価値が上がる。

1. **食材とくいであること**（きのみは溢れてもエナジー化するので無駄にならない）(S23)
2. **進化しない／進化が浅いポケモン**（カイロス19止まり等）(S24)
3. **長時間の睡眠・低頻度の起動**（朝まで回収しない運用）(S18, S37)
4. **おてつだいが速いポケモン**（速いほど早く溢れる）
5. **メインスキル抽選回数**：抽選はおてつだい回数に紐づくため、溢れて止まると抽選も止まる

定量例（S24, Lv30想定, 最大所持数アップLの有無）:
カイロス 3時間20分 → 6時間30分／アブソル 3時間 → 7時間。**3〜4時間の差**は大きい。
一方2段進化するポケモンは素で5時間30分→9時間なので「必須かと言われれば怪しい」。

**EXモードでおてつだい時間が15%延びる**ため、EX前提の運用では溢れにくくなり相対価値は下がる。

### 4-5. 「枠1〜3の金スキル」という考え方

- フレンドメダルにより **銅=Lv10枠、銀=Lv25枠、金=Lv50枠** が金スキル確定になる。
  **銀以降はON/OFF切り替え可能** (S5)。
- Game8 の推奨 (S5, 2025-11-21):
  - **きのみ得意 → 2枠ON**。「『きのみの数S』と『おてつだいボーナス』の2つが出ることを期待」。
    きのみタイプは**欲しいものが両方とも金**なので金確定が純粋に有利。
  - **食材得意・スキル得意 → 1枠だけON**。
    「金のサブスキルは基本的に**おてつだいボーナスのみが欲しい**ので、Lv10とLv25のどちらかをONにして、
    もう一方はOFFにして『◯◯確率アップ』の出現を狙う」。
- 検証Wiki厳選も「**Lv.10と25の解放が評価への影響が極めて大きい**」「Lv.70以降は優先度が低い」と述べる (S10)。
  → `slotWeights: [10, 9, 7, 5, 3]` という現行の設定はこの認識と整合的。
  ただし2026年6月の開放Lv短縮で**Lv70枠の実用性が上がった**ため、4枠目をもう少し上げる余地はある（S26, S41）。
- 抽選確率は白53/青33/金14 (S22)。金確定枠1つだと金7種から均等に1つなので
  「きのみの数S」または「おてつだいボーナス」を引く確率は 2/7 ≒ 28.6%。

```js
    up:   { speed: 100, energy:  35, skill:  30, exp:  28, ing:    0 },
    down: { speed: -100, energy: -80, skill: -25, exp: -20, ing:  +15 }
  },
  ingredient: {
    up:   { ing:  100, speed:  82, energy:  32, exp:  26, skill:  22 },
    down: { ing:  -95, speed: -90, energy: -75, exp:  -20, skill: -18 }
  }
}
```

**根拠**

| 項目 | 値の根拠 |
|---|---|
| berry `up.speed = 100` | 全ソース一致で「▲はおてつだいスピード一強」(S3, S19, S20, S40) |
| berry `up.ing = 0` | きのみとくいに食材▲は実害。0にして「▲がついても加点しない」形に |
| **berry `down.ing = +15`（加点）** | **いじっぱり最強の根拠そのもの**。「食材の確率が下がって実質きのみの獲得率を上げてくれる」(S3)、けんぽけラボの計算でも「いじっぱり > おてスピM」(S39)。負値にすると最強性格がハズレ判定される |
| berry `down.speed = -100` | ×0.93。「全タイプで除きたい」(S31)、おがのD (S20) |
| berry `down.energy = -80` | ×0.88＝おてつだい回数−6.62% (S16)。数字上はスピード▼と同オーダーなので高め。ただしげんき回復ボーナスで救済可能なぶん一段下げる |
| berry `up.energy = 35` | ▼より大幅に低い。睡眠スコア100なら回復上限に当たって死に補正になるため (S9) |
| berry `down.exp / down.skill` | 「いちばん許せる▼」。ゆうかん・やんちゃが当たり扱いされる (S19, S32) |
| ingredient `up.ing = 100` | ×1.20。「食材確率が1.20倍になる性格が最も効率がいい」(S10)、ポケらく「最優先」(S19)、おがの S (S21) |
| ingredient `up.speed = 82` | ×1.11。ぽいずみはゆうかんを筆頭に挙げる (S35) ため高めに。ソース間で割れている |
| ingredient `down.ing = -95` | ×0.80。おがの D「食材確率ダウン系は避けたい」(S21)、Wiki「いじっぱりは避けたい」(S10) |
| ingredient `down.speed = -90` | ×0.93。実損は食材▼より小さいが「全タイプで避ける」文化が強い (S31, S32) ため僅差 |
| 無補正（がんばりや等） | up/down とも0 → 合計0。個体値チェッカーの「**中の上〜上の下くらいの評価**」という評とも整合 |

**このモデルで出る当たり／ハズレ（検算）**

- きのみ: いじっぱり **115**（speed▲100 + ing▼+15）＞ やんちゃ 75 ＞ ゆうかん 80 ＞ さみしがり 20
  → いじっぱりが単独首位、おてスピ▲系が上位を占める。ポケらく・Game8・けんぽけラボと一致。
  ハズレは ひかえめ(−100+0=−100)・ずぶとい(−100+35=−65)・おだやか(−100+30=−70)・れいせい(0−20=−20)。
  S40のハズレリスト（ずぶとい・のんき・ひかえめ・れいせい・おだやか・なまいき）とおおむね一致。
- 食材: うっかりや **82**（ing▲100 + skill▼−18）／れいせい **80**／おっとり **25**／ゆうかん **62**
  → うっかりや・れいせいが二強。S40「最強=うっかりや、れいせい」と一致。
  ハズレは いじっぱり(82−95=−13)・しんちょう(22−95=−73)・ようき(26−95=−69)・ひかえめ(100−90=+10 ＝中庸)。
  ひかえめが「中庸」に落ち着くのは §5-3 の対立を反映した狙いどおりの挙動。

## 8. 実装者への申し送り

1. **`down.ing` を berry でだけ正値にする**のを忘れないこと。ここを負値にすると
   コミュニティ最強格の「いじっぱり」がハズレ判定になり、アプリの信頼性が一発で崩れる。
2. **げんき回復量は ▲低め・▼高めの非対称**にする。上限105で頭打ちになる仕様が理由 (S9, S16)。
3. **おてつだいボーナスとおてつだいスピードMの差は小さく**（10点程度）。
   ソース間で順位が入れ替わる項目なので、どちらかを大きく引き離すと反対派の実感と合わなくなる。
4. **食材タイプの `carry_*` と `berry_s` は運用依存**。線形和では表現しきれないので、
   詳細画面に「長時間放置・無進化なら最大所持数アップの価値は上がる」「食材タイプのきのみの数Sは
   最大所持数アップとセットでないと不利」といった注記を出すのが望ましい。
5. **重みのバージョン**（`weightsVersion`）には調査日 `2026-09-11` を刻み、
   2026-06の開放Lv変更以降のソースを基準にしている旨をREADMEかDATA_SOURCES.mdに残すこと。
