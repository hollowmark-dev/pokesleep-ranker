# ゲームデータの出典と確認メモ

`docs/js/data/` 配下のマスタデータを、いつ・どこで確認したかの記録。
ゲーム側のアップデートで値が変わったら、ここも一緒に更新する。

**確認日: 2026-09-11**（ゲーム側は Ver.3.8.0 / 2026-09-09 適用後の状態）

---

## 1. サブスキル（`SUBSKILLS`）— 17種

| 項目 | 結果 |
|---|---|
| 件数 | 17種（金7 / 青6 / 白4） |
| 出典 | ポケモンスリープ攻略・検証Wiki「サブスキル」 <https://wikiwiki.jp/poke_sleep/サブスキル><br>Game8「サブスキルのおすすめと色(レア度)の解説」 <https://game8.jp/pokemonsleep/542681> |

2サイトで完全一致。SPEC.md に列挙されている17個のidとも過不足なく対応した（id の増減なし）。

**レアリティの呼び方について。** ゲーム内の枠の色は **金 / 青 / 白** の3色で、「銀」という色は存在しない。
SPEC.md の型が `'gold' | 'silver' | 'white'` なので、**青 → `silver`** として格納している。
UI で色名を出す場合は「青」と表示するのが実機に忠実。

内訳:

- 金(gold): きのみの数S / おてつだいボーナス / げんき回復ボーナス / 睡眠EXPボーナス / リサーチEXPボーナス / ゆめのかけらボーナス / スキルレベルアップM
- 青(silver): おてつだいスピードM / 食材確率アップM / スキル確率アップM / スキルレベルアップS / 最大所持数アップL / 最大所持数アップM
- 白(white): おてつだいスピードS / 食材確率アップS / スキル確率アップS / 最大所持数アップS

## 2. サブスキルの解放レベル（`SUBSKILL_UNLOCK_LEVELS`）— **仕様変更あり**

| 項目 | 結果 |
|---|---|
| 現行値 | **10 / 25 / 50 / 70 / 80** |
| 旧値 | 10 / 25 / 50 / 75 / 100 |
| 変更時期 | **Ver.3.6.0（2026-06-25）** |
| 出典 | 公式「Update Contents (version 3.6.0)」 <https://www.pokemonsleep.net/en/news/343133383535303430313835333033303436/><br>（原文: "Unlocks at Lv. 75 → unlocks at Lv.70" / "Unlocks at Lv. 100 → unlocks at Lv.80"）<br>ポケモンスリープ攻略・検証Wiki / Game8 も現行値を 10・25・50・70・80 と記載 |

SPEC.md に既定値として書かれている `[10, 25, 50, 75, 100]` は**旧仕様**。
実装では現行値を `SUBSKILL_UNLOCK_LEVELS` に入れ、旧値は
`SUBSKILL_UNLOCK_LEVELS_LEGACY` として残した（古いスクショを読んだときの参考用）。
SPEC.md の方針どおり、**OCRで実際に読めた解放レベルがあればそちらを優先**すること。

ユーザーのスクショに「Lv.50 / 70 / 80」のロックタグが見えていたという報告とも一致する。

同じ Ver.3.6.0 でポケモンのレベル上限も 65 → 70 に引き上げられている。
公式は「Lv.80 以降に、サブスキルとは別のボーナスを追加することを検討中」としているので、
将来また変わる可能性がある。

## 4. メインスキル（`MAIN_SKILLS`）— 36件

| 項目 | 結果 |
|---|---|
| 出典 | Game8「スキル一覧」 <https://game8.jp/pokemonsleep/542636><br>ポケモンスリープ攻略・検証Wiki「メインスキル」 <https://wikiwiki.jp/poke_sleep/メインスキル><br>ポケらく「ビルドアップ(料理アシストS)」 <https://pokemongo-raku.com/post143163><br>ポケらく「サイコブレイク(きのみゾーン)」 <https://pokemongo-raku.com/post160226> |

- 依頼にあった **料理チャンスS** は収録済み（`cooking_chance_s`）。
- ヘラクロスの **ビルドアップ** は基底スキルが **料理アシストS** なので、基底側も1件として収録した。
- 2026年9月のミュウツーイベントで追加される **サイコブレイク(きのみゾーン)** も収録した。
- 固有名スキル（ほっぺすりすり、りゅうせいぐん等）には `base` に基底スキルのidを持たせ、
  `aliases` に「固有名(基底スキル名)」形式も入れてある（攻略サイト表記のOCR対策）。

**不確実な点:** 攻略サイトによって表記が「固有名」だけだったり「固有名(基底スキル)」だったりする。
実機の個体詳細画面がどちらで表示するか未確認のため、両方を alias に入れて逃げている。

## 6. 重み（`DEFAULT_SETTINGS`）

これはゲーム内データではなく**作者の評価ルール**なので出典はない。`weightsVersion: '2026-09-11.1'`。
`subskillWeights` は4タイプすべてに17id分を必ず持たせる（欠けるとその枠が無得点になる）。
変更したら `weightsVersion` を上げること。

`ADMIN_PASS_HASH` は管理者の合言葉の SHA-256（合言葉そのものはリポジトリに置かない）。
変更するときは `python tools/hash-pass.py <新しい合言葉>` で作り直す。

## 検証スクリプト

データ投入後、以下を機械的に確認済み:

- `node --check` が3ファイルとも通る
- id・表示名の重複なし
- `SPECIES.specialty` がすべて `SPECIALTIES` のidに含まれる
- `NATURES` の up/down がすべて `STATS` のid。上昇/下降の組み合わせ20通りが過不足なし、補正なしがちょうど5件
- `subskillWeights` の4タイプすべてに全17idが存在し、値が0..100の整数
- `natureEffectWeights` が4タイプ × up/down × 5ステータスすべて埋まっており、up が正・down が負の整数
